# Change Control visibility acceptance — 2026-10-29

Scope: phase 1 central visibility, implemented in the existing OSLC backend and React SPA. This is not central Change Request / Change Order write enforcement.

The view reads merge previews, instance bridge jobs, ontology publication jobs, pipeline runs, product versions and governed learning reviews. Review/authorization, execution and delivery are separate. Completed validation is not approval; advisory learning approval is not publication authority; merge registration is not graph publication. Receipts are retained evidence, not a fresh graph verification.

The read API requires registered graph-read access. SQL projects an allowlist of scalar metadata and receipt identifiers rather than retrieving ontology preview bodies or raw tool output. Collection history is paged per source, excludes latest aliases, and reports source coverage. Missing sources are explicit; total failure returns 503. Browser session replacement aborts stale requests and clears selected evidence. Existing owner-service write controls remain unchanged.

Missing credentials returned 403; an unknown source returned 422. Turtle and JSON-LD each parsed to 1,033 triples. All ten service readiness endpoints passed.
