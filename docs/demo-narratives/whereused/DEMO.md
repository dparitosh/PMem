# Where Used — change-impact analysis

**Outcome:** Show upstream and downstream use of a selected entity before an
engineering change is approved.

**Readiness:** The graph contains assemblies, references, requirements, or other
relationships for the prepared entity.

## Talk track and clicks

1. Open **Where Used** with the prepared entity selected.
2. Review direct parents or consumers first.
3. Expand the depth to reveal assemblies, systems, requirements, and dependent
   evidence.
4. Distinguish relationship type and traversal depth.
5. Summarize the affected scope and open a critical entity for supporting data.

**Evidence to call out:** selected entity, traversal depth, relationship type,
affected assemblies/systems, requirement links, and impact count.

**Key message:** Change decisions use explicit graph paths rather than manual
cross-system searches.
