# Import — governed source onboarding

**Outcome:** Show how structured and engineering-standard files enter a
traceable ingestion workflow.

**Readiness:** Ingestion service is ready; artifact storage is writable; the
presenter has an approved XML, XSD, JSON/JSON-LD, CSV, XLSX, PLMXML, STEP, XMI,
ReqIF, or QIF sample appropriate to the selected workflow.

## Talk track and clicks

1. Open **Import** and select **Data import**.
2. Select the source type and approved sample; explain format detection and
   source-profile governance.
3. Start the import and show validation, provenance, and artifact identifiers.
4. Switch to **QIF workflow** only when demonstrating the QIF schema-set path.
5. Follow the resulting identifier into registry or graph evidence.

**Evidence to call out:** source filename and digest, detected standard,
validation outcome, immutable artifact reference, and correlation identifier.

**Key message:** Original evidence is retained and every derived entity remains
traceable to its source.
