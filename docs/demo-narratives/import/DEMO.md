# Import demo

Follow [Import business records](../../DEMO-USER-GUIDE.md#1-import-business-records) and [Register and publish meaning](../../DEMO-USER-GUIDE.md#2-register-and-publish-meaning) in the current guide.

Inspect retained conversion/load status and the separate publication receipt; STEP may hand off to Data Flow. After an unknown acknowledgement, inspect retained status before retrying.
