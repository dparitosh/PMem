# Home — platform orientation

**Outcome:** Establish that DEPO connects governed engineering sources to an
ontology-backed knowledge graph and exposes operational status before users act.

**Readiness:** All service readiness checks pass; registry and graph contain the
approved demo baseline.

## Talk track and clicks

1. Open **Home** and introduce the engineering knowledge lifecycle.
2. Use the ontology registry card to show registered sources and ownership.
3. Use graph profile counts to show published nodes and source distribution.
4. Point out the companion as a context-aware entry point, then keep the answer
   grounded in visible registry or graph evidence.
5. Open one downstream page from the sidebar to show that Home summarizes live
   services rather than static presentation data.

**Evidence to call out:** ontology count, graph node/relationship counts, source
breakdown, service integration status, and request error state when unavailable.

**Key message:** DEPO begins with governed, observable context rather than an
untraceable chatbot response.
