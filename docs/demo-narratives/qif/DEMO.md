# QIF — schema-set to ontology workflow

**Outcome:** Convert a complete QIF XSD schema set into reviewed ontology and
graph artifacts with dependency validation.

**Readiness:** QIF service is ready; use the bundled reference or a complete,
approved related XSD set.

## Talk track and clicks

1. Open **QIF** and choose bundled reference or selected files.
2. Start the schema-set task and follow task progress.
3. Review resolved imports/includes, namespace coverage, warnings, and errors.
4. Inspect the ontology preview and generated artifacts.
5. At `awaiting_approval`, approve publication only after validation passes.
6. Show graph synchronization and the retained event trail.

**Evidence to call out:** task ID, files processed, references resolved, classes
and properties created, reviewer action, artifacts, and graph-sync state.

**Key message:** XSD conversion is dependency-aware, review-gated, and fully
traceable.
