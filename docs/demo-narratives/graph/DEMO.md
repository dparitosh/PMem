# Graph Explorer — contextual digital thread

**Outcome:** Navigate a contextual graph from an engineering entity through its
requirements, product, quality, process, and evidence relationships.

**Readiness:** Neo4j is reachable and contains the demo publication; graph-read
authorization is configured.

## Talk track and clicks

1. Open **Graph Explorer** and search for the prepared business identifier.
2. Select the entity and explain its ontology/source identity.
3. Expand only the relationship types needed for the story.
4. Follow one trace from requirement to design/product entity and one trace to
   quality or manufacturing evidence.
5. Use details and provenance to distinguish asserted from inferred context.

**Evidence to call out:** node identifier, label, ontology prefix, relationship
type, source system, publication version, and provenance.

**Key message:** The graph provides a navigable digital thread with evidence,
not an unexplained network visualization.
