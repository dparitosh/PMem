# Admin — operational control and readiness

**Outcome:** Demonstrate service health, agent/tool inventory, source catalog,
and controlled administrative operations.

**Readiness:** Presenter has an authorized admin role and API keys; destructive
operations are excluded unless explicitly approved for an isolated demo.

## Talk track and clicks

1. Open **Admin** and refresh service health.
2. Review all ten APIs and worker-dependent capabilities.
3. Open **Agentic Components** to show registered agents, coded tools, and
   imported OpenAPI operations.
4. Review service and data-source catalogs, including unavailable dependencies.
5. Explain confirmation controls for cleanup operations without executing them
   in a customer environment.

**Evidence to call out:** service readiness, dependency status, agent/tool ID,
tool approval boundary, source configuration, and request correlation ID.

**Key message:** Agentic capabilities and platform operations remain observable,
bounded, and administratively controlled.
