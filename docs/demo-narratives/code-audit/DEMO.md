# Code Network — software structure and traceability

**Outcome:** Explain repository hierarchy and source dependencies as a navigable
network for architecture and impact review.

**Readiness:** Code analysis data has been generated for the approved demo
workspace; no confidential source content is exposed to unauthorized viewers.

## Talk track and clicks

1. Open **Code Network** and review the workspace summary.
2. Toggle between hierarchy and dependency views.
3. Filter to a known service, file, class, or function.
4. Expand its dependencies and select a symbol for file and line evidence.
5. Relate the observed dependency to an architectural or change-impact question.

**Evidence to call out:** repository path, symbol type, source line, inbound and
outbound dependencies, and selected workspace revision.

**Key message:** Code impact is tied to concrete source locations and dependency
evidence.
