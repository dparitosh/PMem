# Modeling — multi-view engineering model

**Outcome:** Explore semantic, architecture, and diagram representations from a
shared governed model.

**Readiness:** Modeling metadata and graph context are loaded for the chosen
example.

## Talk track and clicks

1. Open **Modeling** and select the view appropriate to the audience.
2. Use the tree to choose a package, system, component, or concept.
3. Fit the diagram, then zoom into relationships and representations.
4. Change view while retaining the business context.
5. Open **Graph Explorer** to show that model views and graph evidence share
   identifiers rather than duplicating data.

**Evidence to call out:** model element ID, hierarchy, representation type,
relationship count, source standard, and graph link.

**Key message:** Multiple engineering views are projections of governed semantic
context.
