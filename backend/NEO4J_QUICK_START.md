# Neo4j setup

The maintained setup guide is [Neo4j on-premises and off-premises](../infra/neo4j/README.md).
It covers self-managed servers, Aura, database names, TLS, credentials and the
connection check. Follow the [application installation sequence](../infra/deployment/README.md)
for the shared environment and backend installation. There is no separate Neo4j
Python environment or second application installer.
